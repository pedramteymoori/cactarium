# System

The **System** tab, `/?tab=advanced`, holds the TV's general settings, read through the PHI bridge, and the dashboard's TV name.

<!-- Screenshot to come: the System tab. -->

* **Switch-off timer.** Shows the TV's setting and turns it off. A new time is set in the TV's own settings, because the values behind the timer are not known.
* **No-signal timer.** Shown only.
* **EasyLink remote control.** Whether the TV's remote controls devices over HDMI-CEC. On or off.
* **Auto movie mode** and **HDMI Ultra HD** per port. Shown only.
* **TV name.** Shown at the top of the dashboard and used as the Home Assistant device name.
* **System information.** The raw system information JointSpace returns, as a table.

The timers and HDMI settings are not available while a web app is open.

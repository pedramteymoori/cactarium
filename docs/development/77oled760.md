# 77OLED760/12 compatibility report

Externally tested on Philips **77OLED760/12**, chassis **TPN258E**, firmware
**058.010.032.001**.

Confirmed on this unit:

- ARM64 installation and automatic server startup after a USB-less cold boot.
- Dashboard access and JointSpace connection using existing pairing credentials.
- Cactarium home screen displayed with the Home button after a cold boot.
- Custom app selection and ordering displayed correctly.
- The owner tested several applications successfully; not every app was tested.

Launcher installation with an API token used the separately proposed preflight
fix. This report does not claim full compatibility for all applications or
features. No device identifiers or personal app selection are included.
